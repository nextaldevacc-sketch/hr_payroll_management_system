## Responsive Architecture Rules Verified

1. **Zero Viewport Horizontal Scroll**: `document.documentElement.scrollWidth <= window.innerWidth` across all tested roles and viewports.
2. **Table Container Scrollers**: All data tables are wrapped in `overflow-x-auto` to ensure horizontal scrolling is confined within the card container rather than breaking the page.
3. **Responsive Drawers & Modals**: Settings drawers, modal dialogs, and slideouts feature `max-h-[90vh]` and vertical scroll wrappers.
4. **Mobile Navigation Drawer**: Sliding navigation menu supports full touch targets (>= 40px) and displays brand, navigation links, and session status clearly.
5. **Tap Targets**: Mobile buttons and interactive wells provide a minimum 40px to 44px touch target.
